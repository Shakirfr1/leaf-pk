# LEAF PK Website — V7

Production-ready static Vercel website for https://www.leafpakistan.com/

## Deploy updates
Open Command Prompt inside this folder and run:

    vercel --prod

Then hard refresh the live site with Ctrl + Shift + R.

- Quick quotation builder that opens WhatsApp with structured details
- Improved mobile layout and responsive controls
- Active sticky navigation and accessibility improvements
